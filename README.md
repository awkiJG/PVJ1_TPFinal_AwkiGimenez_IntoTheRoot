## 📋 Cómo hacer privado este repositorio / How to Make This Repository Private

### 🇪🇸 Español

Para hacer privado tu repositorio de GitHub, sigue estos pasos:

#### Opción 1: Desde la interfaz web de GitHub

1. Ve a tu repositorio en GitHub: https://github.com/awkiJG/PVJ1_TPFinal_AwkiGimenez_IntoTheRoot
2. Haz clic en **"Settings"** (Configuración) en la barra de navegación del repositorio
3. En la página de configuración, desplázate hacia abajo hasta la sección **"Danger Zone"** (Zona de peligro)
4. Busca la opción **"Change repository visibility"** (Cambiar visibilidad del repositorio)
5. Haz clic en **"Change visibility"** (Cambiar visibilidad)
6. Selecciona **"Make private"** (Hacer privado)
7. Confirma escribiendo el nombre del repositorio cuando se te solicite
8. Haz clic en el botón de confirmación

#### Opción 2: Usando GitHub CLI (gh)

Si tienes instalado GitHub CLI, puedes ejecutar:

```bash
gh repo edit awkiJG/PVJ1_TPFinal_AwkiGimenez_IntoTheRoot --visibility private
```

#### ⚠️ Consideraciones Importantes

- **Necesitas ser el propietario del repositorio** o tener permisos de administrador
- Los repositorios privados pueden tener limitaciones dependiendo de tu plan de GitHub:
  - Cuentas gratuitas: repositorios privados ilimitados con colaboradores limitados
  - GitHub Pro/Team/Enterprise: más opciones y colaboradores
- Una vez privado, solo tú y los colaboradores que invites podrán ver el repositorio
- Los forks públicos del repositorio NO se volverán privados automáticamente

### 🇬🇧 English

To make your GitHub repository private, follow these steps:

#### Option 1: From GitHub Web Interface

1. Go to your repository on GitHub: https://github.com/awkiJG/PVJ1_TPFinal_AwkiGimenez_IntoTheRoot
2. Click on **"Settings"** in the repository navigation bar
3. On the settings page, scroll down to the **"Danger Zone"** section
4. Find the **"Change repository visibility"** option
5. Click on **"Change visibility"**
6. Select **"Make private"**
7. Confirm by typing the repository name when prompted
8. Click the confirmation button

#### Option 2: Using GitHub CLI (gh)

If you have GitHub CLI installed, you can run:

```bash
gh repo edit awkiJG/PVJ1_TPFinal_AwkiGimenez_IntoTheRoot --visibility private
```

#### ⚠️ Important Considerations

- **You need to be the repository owner** or have admin permissions
- Private repositories may have limitations depending on your GitHub plan:
  - Free accounts: unlimited private repositories with limited collaborators
  - GitHub Pro/Team/Enterprise: more options and collaborators
- Once private, only you and invited collaborators can see the repository
- Public forks of the repository will NOT automatically become private
